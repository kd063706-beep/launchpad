# LaunchPad — лендинг студии заказной веб-разработки

Готовый статический сайт: чистый HTML5, модульный CSS3, немного vanilla JavaScript.
Без сборщиков и зависимостей — открывается двойным кликом по `index.html`.

## Как открыть

1. Откройте `index.html` в браузере.
2. Или запустите локальный сервер (шрифты и всё остальное работают и так, но так удобнее):

```powershell
cd d:\test
python -m http.server 5500
# затем откройте http://localhost:5500
```

Либо в VS Code — расширение Live Server → «Open with Live Server».

## Структура файлов

```
index.html            вся разметка страницы
css/variables.css     цвета, шрифты, отступы, тайминги (дизайн-токены)
css/base.css          reset, типографика, сетка, разделители, доступность
css/components.css    кнопки, шапка, hero, работы, аккордеон, шаги, цены, футер
js/main.js            меню, плавная прокрутка, появление блоков, живой макет
```

## Что легко изменить

- **Точный адрес почты** — заменён на `launchpad.studio@mail.ru` в трёх местах
  (`index.html`: блок «Контакты» и футер). Поменяйте на свой.
- **Тексты** — все на русском, лежат прямо в `index.html` рядом с нужным блоком.
- **Цвета** — правятся в одном месте, в `css/variables.css` (`--accent`, `--bg`, `--surface`, `--line`).
- **Работы** — каждый проект это `<article class="work">`; классы `work--lg / work--md / work--sm / work--half`
  задают размер плитки в сетке.

## Важное про акцент

Неоновый бирюзовый `#00F2FE` и его свечение используются намеренно экономно:
главные кнопки, активный пункт меню, фокус, одна подсвеченная ячейка макета
и лёгкий отсвет в фоне. Не добавляйте свечение к другим элементам — эффект пропадёт.

## Доступность

- Ссылка «Перейти к содержанию», `aria-expanded` у меню и аккордеона, `aria-label` у бургера и соцсетей.
- Видимый `:focus-visible` акцентным цветом.
- Учитывается `prefers-reduced-motion`: анимации отключаются, блоки видны сразу.
